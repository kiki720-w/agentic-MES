# 第35步：制造智能控制层与L3排产智能体验收

## 目标

本步把产品从“再造一套MES”调整为“连接并增强现有制造系统的智能控制层”，并把L3能力从单工单异常动作迁移到跨系统约束下的滚动排产。

正式产品不成为订单、库存、质量或设备实绩的权威来源。既有ERP、MES、WMS、QMS和设备平台继续负责各自业务事实；本产品保存带来源、源版本、观测时间和校验和的制造数字镜像，以及由此产生的计划、证据和审计链。

## 运行结构

```text
ERP / MES / WMS / QMS / 机床 / 传感器
                  │
          工厂边缘适配器
      认证、字段映射、版本与防重放
                  │
          标准排产快照（只追加）
                  │
       统一制造语义 + 有限产能APS
                  │
    L3排产智能体：感知、生成、去重、提交
                  │
         人工审批与发布策略门
                  │
       专用回写适配器 → 原业务系统
```

## 已实现

- 根页面改为制造智能控制塔，展示系统连接面、制造镜像、排产状态、约束缺口和L3运行边界。
- 原生产控制台迁移到`/simulator`，且仅在`AUTONOMOUS_MES_SIMULATOR_MODE=true`时开放。
- 正式模式关闭内置工单、报工、设备、资源和质量写路径；签名连接器、只读镜像、排产和治理接口保留。
- 新增`SchedulingSnapshot`及PostgreSQL迁移`0023`。同一来源、车间和源版本幂等；内容不一致时拒绝覆盖。
- 新增HMAC签名的`POST /api/v1/connectors/v1/scheduling-snapshots`，接收外部工单、工序、资源、WMS齐套状态和QMS冻结状态。
- 外部快照存在时成为APS权威输入；内置MES投影只作为无外部快照时的模拟器兼容输入。
- L3智能体按输入指纹去重，自动生成有限产能计划，并在存在分配结果时提交审批。
- 快照、工单、工序、设备、资源和质量变化均可通过Outbox触发重排。
- 自然语言“重新排产”直接调用L3排产智能体，并返回计划ID、缺口与策略决策。

## L3权限边界

L3允许：读取获授权车间快照；运行确定性APS；生成或复用计划；提交计划供审批；记录触发原因、输入指纹和审计事件。

L3禁止：批准自己的计划；发布计划；绕过物料、质量、设备或产能约束；直接写ERP/MES/WMS/QMS数据库；直接控制PLC、CNC或传感器；把DeepSeek输出当作生产指令。

计划发布权固定为`HUMAN_SUPERVISOR_ONLY`。大模型只用于自然语言理解和解释，排产可行性、状态转换、并发版本与审批规则由确定性代码执行。

## 接口契约摘要

外部快照至少包含：

- 来源系统、车间、不可变源版本和带时区的观测时间；
- 工单、冻结的产品/工艺/BOM版本、工序顺序、工作中心、数量、交期和优先级；
- WMS物料齐套和QMS质量冻结；
- 人员、单元或设备产能、能力代码、在线状态和正常/加班容量。

所有写入请求必须通过已有HMAC时间窗、Nonce防重放和原始请求体签名校验。
