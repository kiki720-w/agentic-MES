# 开源 MES 底座选型办法

## 原则

目标不是选择功能最多的项目，而是选择最适合承载机械加工领域模型、制造事件和 Agent 工具层的底座。页面外观不计入硬门槛。

## 候选池

1. OpenMES：优先验证中小制造企业的工单、追溯和用户操作闭环。
2. point85/mes-ai：优先验证工业集成、事件采集和 AI 扩展结构。
3. salbotics-ssd-mes：优先验证路线、进出站、谱系及 Web API。

候选名称不代表已经批准商用。必须读取仓库根目录 LICENSE、依赖许可证和历史提交，确认具体版本的法律与维护风险。

## 硬门槛

- 许可证允许目标商业模式；存在不确定性即暂停采用。
- 能在干净环境中按文档重复部署。
- 核心数据可以导出，不形成不可控锁定。
- 不要求 Agent 直接写数据库。
- 身份认证、对象权限和审计能够补强。
- 可以新增事件发布、工具 API 和幂等控制。

## 评分

通过硬门槛后，按 `selection/mes-candidate-scorecard.csv` 评分。每项 0—5 分；加权得分满分 100。低于 70 分不作为主底座，70—79 分仅可用于原型，80 分及以上才进入二次安全评审。

## 选型验证步骤

1. 固定仓库 commit 和许可证证据。
2. 记录部署时间、依赖和失败点。
3. 导入同一份虚拟工厂数据。
4. 演示同一套订单—返工—追溯流程。
5. 用同一套 API 测试和异常测试评分。
6. 做代码结构、权限、审计和依赖安全检查。
7. 估算保留、封装和重写模块的工作量。
