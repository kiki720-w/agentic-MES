# 第七步质量与返工闭环验收记录

日期：2026-09-12  
结论：后端质量闭环和 PostgreSQL 迁移通过。

## 已实现

- 已完成工序才能创建质量检验任务。
- 检验支持合格与不合格判定，并使用乐观锁防止重复处置。
- 不合格判定强制填写缺陷代码，产品状态进入 `QUARANTINED`。
- 隔离品只能经人工批准后进入 `REWORK_APPROVED`。
- 返工批准必须包含返工工序路线，原工单与原检验记录不被覆盖。
- 创建检验、检验合格、产品隔离、批准返工均写入制造事件 Outbox。
- 新增质量检验查询、结果记录和返工批准 API。
- 新增 Alembic 迁移 `0006_quality_inspections`。

## 安全边界

Agent 可解释质量异常并形成建议，但本步骤未向 Agent 开放质量处置写权限。隔离解除和返工路线批准仍由有权限的人员执行。

## 验证

- 自动测试：30 项通过。
- PostgreSQL 真实迁移：通过。
- Ruff：通过。
- Mypy strict：通过。
