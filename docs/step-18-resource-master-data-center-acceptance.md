# 第十八步：制造资源主数据中心验收

结论：通过。MES已具备可独立运行的刀具、夹具、NC程序和量具权威台账，同时保留外部系统替换数据来源的标准边界。

## 数据模型

统一资源记录包含：类型、编号、版本、名称、状态、刀具剩余寿命、量具校准到期时间、来源系统、外部引用、来源更新时间、MES乐观锁版本和审计时间。

NC程序以“编号+版本”为独立主数据；非版本资源使用稳定编号。`sourceSystem=MES`表示内置台账权威，其他值可表示ERP、PLM、DNC、刀具柜或计量系统适配器。

## 写入与同步规则

- 新增资源与Outbox事件原子提交。
- 状态更新要求MES`expectedVersion`，防止并发覆盖。
- 外部`sourceUpdatedAt`早于当前记录时拒绝，防止延迟消息倒灌旧状态。
- 重复资源键拒绝，不静默覆盖。

## 生产约束

- 加工实绩只提交资源身份，服务端读取台账状态、程序发布态和刀具寿命。
- 检验结果只提交量具身份与测量时间，服务端读取量具状态和校准期限。
- 生产实绩继续保存不可变快照；主数据后续变化不会篡改历史谱系。

## 安全边界

当前API用于受信任的MES业务层和未来适配器，尚未开放给Agent。Agent仍只有R0/R1查询和R2建议能力，不能修改主数据或生产状态。

## 下一决策点

下一步需要确定首个真实外部连接对象及协议。不同选择会导致完全不同的适配器工作：ERP工单/BOM、PLM图纸/工艺、DNC程序、刀具柜寿命或计量系统校准。未确定目标系统前，可以继续完善内置台账UI，但不应臆造厂商字段和同步协议。
