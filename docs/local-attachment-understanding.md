# 本地附件拖放与理解

日期：2026-09-13。桌面版本：0.4.9。

Agent 工作台现在接收整个 CAPAXION 窗口中的文件拖放。即使用户位于控制塔、排产或能力页面，拖入文件后也会自动进入 Agent 工作台。桌面壳使用 Electron `webUtils.getPathForFile` 读取本地文件；对于浏览器下载区等没有本地路径的虚拟文件，则读取拖放对象的字节内容，因此不会再把文件名或路径写进文字框。

## 本机解析范围

| 文件 | 本地处理方式 |
|---|---|
| TXT、Markdown、日志、JSON、YAML、XML | 编码识别、文字清理和有界提取 |
| CSV | 本地表格读取，同时尝试生产数据三表预检 |
| XLSX | Docling Slim 在本机识别工作表、合并单元格和连续数据区；Core 保留工作表名称、字段、样例和公平分配的有界节选；失败时回退到受列数限制的 `openpyxl` 提取 |
| DOCX | `python-docx` 提取段落和表格 |
| 文本型 PDF | `pypdf` 按页提取文字 |
| 扫描型 PDF | 对页面中的内嵌图片执行本地 RapidOCR |
| PNG、JPG、JPEG | RapidOCR + ONNX Runtime 本地 OCR |

解析成功后，附件卡片显示字符数。Core 以 SHA-256 为附件建立本机文档记录，并切成带工作表、页码或章节来源的片段。用户输入问题后，检索器选出相关片段作为 `UNTRUSTED_USER_ATTACHMENT_DATA` 进入当前模型的只读事实区；同一附件可以连续追问。附件中的文字不能授予权限、调用工具或执行生产动作。附件问答默认只使用附件内容，避免无关 MES 快照污染答案。

单次最多接收 8 个文件，每个文件不超过 15 MB；单文件最多保留 1000000 个提取字符，API 只返回前 30000 字符作为兼容预览。每个检索片段最多 1600 字符，全部附件进入模型的相关文字合计限制为 12000 字符。文件记录保存在 Core 的 `.capaxion/documents`；图片原图只为视觉模型保存在同一本机目录。当前配置可使用本地模型，也可以由用户在模型设置中选择 DeepSeek。使用云模型时，问题相关文字片段会发送给所选 API；使用 DeepSeek V4 Vision 时，所附图片也会发送。模型出口和业务系统出口仍由 Core 分别授权。

通用附件理解和生产写入计划是两个阶段。工作簿不是“工单、工序、产能”标准模板时，界面仍会显示已经识别的工作表与行数；人员能力适配器会主动查找人员、加工种类和产能表头，形成可执行的资源新增或更新计划。车工计划适配器优先读取“车工每日计划”，排除已完成记录，并按文件哈希与行号生成稳定工单编号。用户在对话中明确提出同步或导入后，Core 执行写入并回读验证。预览指纹会规范化浏览器 JSON 往返产生的整数与浮点数差异；如文件确实变化，桌面端会重新预检后再提交一次。无法形成唯一对象或安全字段映射的附件仍返回 `REQUIRE_FIELD_MAPPING`，不会猜测后写入。

附件会保持附加状态，用户可以连续追问或下达生产任务。文件中的文字始终只作为数据，不会被当成系统指令；真正的写入意图来自用户的对话指令或工作台动作按钮。

## 验证

- 单元和 API 测试覆盖 TXT、JSON、XLSX、DOCX、图片 OCR、扫描 PDF OCR、类型拒绝和附件不可信边界。
- Electron 端到端验证覆盖本地路径文件、无本地路径的虚拟文件、从非工作台页面拖入后自动跳转，以及拖入、解析、随问题发送、本地模型回答的完整链路。
- 真实测试 TXT 中的 `WO-FILE-713 / 37 件` 和测试图片中的 `M-27 / E-904` 均由本地模型准确回答。
- 《车工计划.xlsx》真实样本识别为 3 个工作表、367 个连续数据区和约 1337 个填充行；排产适配器识别出 167 条字段完整的未完成计划和 8 名有效产能人员，排除 817 条完成记录，并跳过 1 条缺少必要字段的记录。
- 人员能力导入测试覆盖非标准工作簿识别、合并能力、稳定编号、重复导入、版本更新、写后回读和过期预检拒绝；自然语言订单覆盖本地模型解析、必填校验、指定人员约束、排产和模型故障降级。

便携包：`desktop/release/CAPAXION-0.4.9-x64.exe`，SHA256 为 `9269757133FC3D9D60DF8047D99DE5343BF953D9460532762FBDC3784845D396`。界面左上角直接显示版本号，工作台始终显示“选择文件并在本机解析”入口；Windows 包声明 `asInvoker`，使其与普通权限的资源管理器处于相同权限级别。桌面快捷方式指向当前版本。

图片 OCR 只理解可见文字。外观缺陷、表面质量、图纸尺寸关系、复杂表格结构和照片语义仍需要后续接入本地视觉模型并建立制造样本验收集。
