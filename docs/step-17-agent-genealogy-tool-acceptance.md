# 第十七步：Agent制造谱系只读工具验收

结论：通过。完整产品谱系已经成为受治理的Agent证据工具，不再只是供页面直接查询的REST数据。

## 工具契约

- 名称：`get_product_genealogy`
- 风险：`R1`敏感只读
- 输入：Agent上下文、用途和产品序列号
- 输出：版本、工序、人员、设备、物料、刀具、夹具、NC程序、检验和量具证据
- 时间语义：返回`asOf`及各事实自身时间，不以模型记忆替代实时数据

## 授权与审计

工具先由产品序列号解析关联工单，再按工单所属车间执行scope授权。`ALLOW`、`DENY`和`NOT_FOUND`均产生`AgentToolCallRecorded`事件，记录Agent、发起主体、用途、工具版本、风险和目标对象。

## 目标对齐

该能力保持阶段一L2边界：Agent只能读取并解释制造证据，不能发布NC程序、修改检验结果、解除隔离或控制设备。

## 下一决策点

当前刀具、夹具、程序和量具状态以受信任接口提交的不可变快照为依据。继续进入真实集成前，需要确定权威主数据来源：由本MES自建台账，还是连接现有ERP/PLM/DNC/刀具柜/计量系统。这个选择会决定下一组适配器和数据所有权边界。
