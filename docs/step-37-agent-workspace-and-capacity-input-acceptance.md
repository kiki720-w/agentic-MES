# 第37步：Agent工作台、工艺产能输入与大样本界面验收

## 目标

把旧排产项目中已经验证过的“订单数量 × 单件工时、人员技能、正常/加班产能、缺口与排产结果”保留下来，但不复制巨型前端状态和单页长表。CAPAXION 继续作为已有 ERP、MES、WMS、QMS 与设备之上的智能控制层。

## 已实现

- `/workspace`：文字、XLSX/CSV、图片和PDF的统一入口；表格先预检再确认。
- `/capacity`：人员与工作单元的新增、修改、停用、能力代码和正常/加班分钟维护。
- `/planning`：只呈现输入快照、工件工序需求和排产启动参数。
- `/planning/results`：独立全宽结果，支持100条一页的搜索与翻页，展示排产创建者、提交者、审批者和发布者。
- 虚拟员工身份：`scheduling-agent-l3-v1`在界面中标记为“虚拟员工「衡策」· L3”。
- 工时公式：`准备工时 + (计划数量 - 良品 - 报废) × 单件工时`。
- 工时优先级：快照工艺标准 > 人工工序覆盖 > 默认回退值。
- XLSX模板：工单、工序、产能三张工作表，可直接下载。
- 安全导入：5 MB/每表5000行上限、字段与关联校验、内容指纹确认、原文件不持久化。
- 产能修改：乐观锁版本校验与`PlanningResourceUpdated`事件审计。

## 安全边界

- L3 Agent可以生成并提交方案，但不能批准或发布。
- DeepSeek仅参与诊断解释，不直接写数据库或控制设备。
- 图片/PDF当前只有附件预览；未选定视觉模型和数据出厂策略前，不宣称已完成多模态理解。
- Excel上传不会立即成为排产事实，必须由计划员确认同一预检指纹。
