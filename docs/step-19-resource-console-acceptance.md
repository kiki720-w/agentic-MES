# 第十九步：制造资源可视化控制台验收

结论：通过。制造资源主数据从后端能力变为可直接操作和演示的产品页面。

## 页面能力

- 新增独立“制造资源”导航，避免把资源台账塞进过长的生产工单页面。
- 卡片展示刀具、夹具、NC程序和量具的状态、版本、权威来源及类型特有数据。
- 支持按资源类型筛选。
- 新增资源表单按类型采集程序版本、刀具寿命或量具校准期限。
- 表单只登记`sourceSystem=MES`的内置台账；外部来源必须通过未来适配器写入，避免在人工页面伪造外部来源。

## 仍保持的边界

页面不能发布生产控制指令，也不向Agent开放主数据写工具。状态更新API已经版本化，但正式的状态维护工作流仍需结合角色权限和变更原因页面。

实现通用CSV批量导入的“上传前预检—逐行错误—确认提交”流程，并输出稳定模板字段，作为没有API的中小工厂最低成本接入方式。
