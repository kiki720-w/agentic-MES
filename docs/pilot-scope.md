# 阶段一试点范围与成功标准

版本：0.1（范围已冻结）

## 1. 目标

用虚拟车间证明以下链路能够真实运行：订单进入 MES，形成工单和工序任务，设备事件与工单上下文关联，检验和返工形成闭环，最终能够按产品序列号追溯；Agent 只能通过授权工具读取数据、解释异常并生成建议。

本阶段不验证无人控制机床，也不训练基础大模型。

## 2. 试点对象

- 车间：精密机械加工虚拟车间 `WS-MACH-01`
- 设备：10 台，详见 `data/virtual-factory.json`
- 产品：传动轴、阀体、精密法兰
- 角色：计划员、班组长、操作员、检验员、工艺工程师、系统管理员、只读 Agent
- 标识粒度：关键件按序列号追溯，普通在制品保留批次字段

## 3. 必须覆盖的业务流

1. ERP 模拟器下达生产订单。
2. MES 创建并下达工单。
3. 按工艺路线生成工序任务并派工。
4. 操作员确认物料、设备、刀具和程序版本后开工。
5. 设备模拟器上报运行、空闲、停机、报警和加工完成事件。
6. MES 完成报工并创建检验任务。
7. 合格件转入下一工序；不合格件进入隔离和返工。
8. 完工后可以查询订单、人员、设备、刀具、程序、工艺版本、加工事件和检验结果。

## 4. 异常场景

| 场景 | 系统行为 | Agent 行为 |
|---|---|---|
| 紧急插单 | 创建高优先级订单，标记受影响任务 | 解释交期影响并提出候选调整建议 |
| 设备停机 | 暂停关联工序并形成异常 | 找出受影响订单和可替代设备 |
| 物料短缺 | 阻止不满足齐套条件的开工 | 汇总缺料范围并生成催办建议 |
| 质量失败 | 隔离产品并进入不合格处置 | 汇总相关工序、设备和批次证据 |
| 刀具异常 | 记录刀具状态并暂停相关任务 | 说明风险并建议换刀/复检，不发控制指令 |

## 5. Agent 权限边界

允许：查询工单、设备、产品谱系、质量、异常、工序历史和受控知识库；创建告警草稿和建议草稿。

禁止：修改排程、释放不合格品、修改工艺或 NC 程序、改变加工参数、删除记录、直接控制设备。

每次工具调用必须记录 Agent、模型、提示版本、工具、参数摘要、结果、延迟、授权结论和关联业务对象。

## 6. 退出标准

- 10 个端到端验收用例全部通过。
- 关键生产事件成功接收率不低于 99%，上下文关联率不低于 95%。
- 重复事件不产生重复报工；断网事件恢复后可补传。
- 任一序列号可以还原完整制造谱系。
- Agent 的实时答案来自工具，不把模型记忆当作生产事实。
- 所有越权工具调用均被拒绝并留下审计记录。
- DeepSeek API 不可用时，MES 核心业务仍可运行。
