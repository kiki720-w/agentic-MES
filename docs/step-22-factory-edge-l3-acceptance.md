# 第二十二步：工厂边缘实例与L3审批边界验收

结论：通过。部署模式固化为工厂独立实例；当前本地实例按用户确认启用实验性L3，并新增审批人白名单硬门。

## 部署上下文

- `deploymentMode=FACTORY_EDGE`
- 每个实例配置稳定`organizationId`和`factoryId`
- 生产数据声明使用专用数据库隔离
- 云端控制平面保持可选且当前未连接

单工厂实例不需要在每张事务表重复多租户过滤，降低现场越权和配置错误风险。未来控制平面只能管理版本、许可证、连接状态和脱敏指标，不成为现场生产动作的实时依赖。

## L3启用状态

当前本地`.env`已设置L3执行开关，服务健康状态返回`L3_EXPERIMENTAL`。`.env`不进入Git。

L3仍受以下限制：

- 只执行已注册白名单动作；当前仅为设备恢复后的工序复工。
- 必须存在`PENDING_APPROVAL`提案并由配置白名单中的审批人提交原因。
- 执行前重新检查设备健康、工单版本、工序状态和幂等键。
- 不允许Agent直接控制PLC/CNC、改变参数、发布NC程序或放行不合格品。
- DeepSeek仅生成解释，不决定安全条件。
