# 第十六步：量具校准与检验追溯验收

结论：通过。质量结果必须引用量具及测量时点的校准有效期，过期量具不能形成有效检验结果。

## 已实现

- 检验结果记录量具编号、测量时间和校准到期时间。
- 领域规则比较测量时点与到期时点，过期即拒绝，检验保持`OPEN`。
- 量具证据进入质量事件、检验查询和产品序列号谱系。
- 控制台演示路径使用明确的演示量具快照，不由模型生成。

## 边界

当前保存的是检验时不可变证据快照。量具台账、周期校准工单和第三方证书文件属于后续计量管理模块；正式接入时应以受信任台账为唯一状态来源，客户端不得自行声明校准有效。
