# ADR-0009：测试与质量门禁

状态：Accepted  
日期：2026-08-30

## 测试层次

1. 领域单元测试：状态机、数量守恒、版本冻结、质量隔离规则。
2. 属性测试：随机命令序列不能产生非法状态或负数量。
3. repository集成测试：真实PostgreSQL、迁移、事务和并发。
4. API契约测试：OpenAPI、错误、幂等、授权和分页。
5. 事件测试：重复、乱序、失败重试、隔离和重放。
6. Agent契约测试：假模型、工具白名单、越权、提示注入、过期数据和模型故障。
7. 端到端测试：执行`acceptance-tests.md`和停机—返工推演。

## 合并门禁

- 格式、lint、静态类型和测试全部通过。
- 新状态转换必须更新机器定义、事件Schema和测试。
- 数据库迁移必须在空库和前一版本库验证。
- API破坏性变化必须有新版本或迁移方案。
- 安全相关代码不得降低默认拒绝、审计或Agent工具边界。
- 领域与Agent安全关键模块要求分支覆盖率≥90%；全项目初期目标≥80%，但不以覆盖率替代场景验证。

## 发布门禁

通过备份恢复、模型断开、边缘断网补传、重复事件、越权调用、提示注入和质量隔离测试后，才可进入真实车间影子运行。
