# ADR-0003：数据库与迁移

状态：Accepted  
日期：2026-08-30

## 决策

PostgreSQL 17作为阶段一唯一生产事务数据库。首版不强制TimescaleDB；高频原始设备信号进入边缘缓存或后续时序扩展，MES只保存业务相关状态、报警、加工周期和摘要。

Schema按模块划分；所有表包含`created_at`，可变业务表包含`updated_at`和乐观锁`version`。业务主键使用UUIDv7兼容标识或服务生成的时间有序UUID；人类可读编号单独唯一。

迁移规则：

1. Alembic迁移只前进，生产环境禁止自动降级。
2. 破坏性迁移采用expand/migrate/contract三阶段。
3. 已投产记录不做物理级联删除。
4. 时间统一存储UTC的`timestamptz`，展示时使用Factory timezone。
5. JSONB只用于事件载荷和不稳定扩展字段，核心业务关系使用规范化列和外键。
6. 每个请求设置工厂/车间安全上下文；应用授权为主，关键表可增加RLS作为纵深防御。

备份目标：试点RPO≤24小时、RTO≤4小时；进入真实车间前提升到RPO≤15分钟、RTO≤1小时并做恢复演练。
