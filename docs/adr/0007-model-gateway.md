# ADR-0007：模型网关与DeepSeek适配器

状态：Accepted  
日期：2026-08-30

## 决策

建立供应商中立的`ModelGateway`端口，首个适配器连接DeepSeek API。领域模块不引用任何模型SDK。配置决定模型供应商、模型名、超时、重试、预算和数据策略。

网关能力：结构化输出、工具调用、超时、有限重试、熔断、token/成本统计、提示版本、模型版本、脱敏、审计和降级。不得把完整数据库、未授权图纸、NC程序或客户敏感信息发送到云端。

工具执行流程：

1. 模型只生成工具调用意图。
2. 工具网关重新验证身份、scope、参数和风险。
3. MES应用服务执行只读查询或创建建议草稿。
4. 工具结果按最小必要字段脱敏后返回模型。
5. 最终答案必须携带数据时间与来源引用。

## 失败策略

- 超时或API不可用：返回明确不可用状态，不编造生产答案。
- 工具参数无效：最多一次结构化纠正，不无限循环。
- 实时数据过期：标记STALE_DATA，禁止形成确定性结论。
- 模型服务整体关闭：MES人工操作、设备采集、质量和追溯继续运行。

## 可替换性验证

所有Agent评测必须能以假模型适配器运行；DeepSeek适配器通过契约测试，不成为领域测试依赖。未来可增加本地模型或其他API而不改业务代码。
