# ADR-0005：身份、授权与审计

状态：Accepted  
日期：2026-08-30

## 决策

系统使用OpenID Connect/OAuth 2.0接口，不自建密码协议。开发期提供可替换的本地OIDC测试身份；试点部署首选Keycloak，企业客户可对接其现有IdP。

授权使用RBAC+对象范围：角色决定动作集合，scope限制Factory、Workshop、WorkCenter、Equipment、产品或文档密级。默认拒绝。Agent使用独立service account，并携带发起用户上下文和purpose，不继承超级管理员权限。

审计记录追加写，至少包含主体、代理主体、动作、对象、请求、策略结论、前后哈希、来源IP/客户端、结果和理由。认证日志与业务审计分开保存。

## 安全约束

- 不在代码、提示词或事件中存储密钥。
- 访问令牌短期有效；服务凭据通过环境/密钥管理注入。
- Agent工具网关不接受模型自报角色。
- 工艺发布、报废、让步接收等高风险动作即使未来提供工具，也必须实施职责分离和显式审批。
- 任何直接SQL、设备控制和任意URL工具永久不注册给LLM。
