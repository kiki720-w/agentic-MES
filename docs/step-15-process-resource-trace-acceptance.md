# 第十五步：加工资源实绩追溯验收

结论：通过。加工会话不再只记录人员、设备和物料，还冻结刀具、夹具与NC程序版本快照。

## 已实现

- `TOOL`：记录刀具编号、状态和剩余寿命；不可用或寿命为零时拒绝。
- `FIXTURE`：记录夹具编号；非可用状态时拒绝。
- `NC_PROGRAM`：记录程序编号及版本；未发布或缺少版本时拒绝。
- 三类资源随执行会话在同一事务中持久化，并进入产品序列号谱系。
- 追溯页面显示资源类型、编号、版本和刀具寿命快照。

## 安全边界

这是生产实绩与前置条件校验，不向Agent开放发布程序、修改参数或控制机床的能力。状态字段当前来自受信任业务接口；接入真实刀具柜、DNC或PLM后应由相应主数据适配器提供并签名/审计。

## 下一步

给质量检验绑定量具与校准有效期，完成“测”的独立实绩记录；随后将全谱系作为Agent只读证据工具，而不是让模型推测制造事实。
