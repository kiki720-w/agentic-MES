# 第二十步：制造资源CSV导入验收

结论：通过。没有API能力的工厂可以使用稳定CSV模板批量导入资源，同时保留预检、确认和原子性安全门。

## 接口

- `GET /api/v1/master-data/manufacturing-resources/import-template`：下载稳定CSV表头。
- `POST .../import-preview`：解析但不写库，返回逐行标准化结果、错误和SHA-256预检指纹。
- `POST .../import`：携带相同文件、来源和预检指纹确认导入。

## 安全与质量

- 文件最大1 MB、最多500行，空文件和错误表头拒绝。
- 每行复用与人工登记相同的领域规则。
- 文件内重复键和数据库已有键在预检阶段报告。
- 预检后内容变化会导致指纹不符，拒绝提交。
- 所有资源和Outbox事件使用一个事务；任意键冲突时整批回滚。
