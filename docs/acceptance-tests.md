# 阶段一端到端验收用例

| ID | 用例 | 通过条件 |
|---|---|---|
| AT-01 | 订单转工单 | 订单生成正确数量、产品版本和交期的工单 |
| AT-02 | 工艺路线展开 | 工单按当前有效版本生成有序工序任务 |
| AT-03 | 派工与开工 | 资质、设备能力、物料和版本校验通过后才能开工 |
| AT-04 | 设备事件关联 | 运行/停机/报警事件关联到正确设备、工单和工序 |
| AT-05 | 重复与乱序 | 重复事件不重复报工，乱序事件被识别并审计 |
| AT-06 | 断网补传 | 边缘端恢复后补传且保持原始事件时间 |
| AT-07 | 质量与返工 | 不合格品被隔离，批准后生成返工路线并保留原谱系 |
| AT-08 | 序列号追溯 | 可查询人、机、料、法、测、时间和所有版本信息 |
| AT-09 | Agent 只读问答 | 答案引用工具返回的数据、时间戳和业务对象 |
| AT-10 | Agent 越权防护 | 所有写生产状态或控制设备的尝试被策略层拒绝并审计 |

## 演示主线

创建传动轴订单，执行至精车；模拟 `LATHE-02` 停机，使 Agent 找出受影响产品并建议候选设备；人工不执行建议。随后完成加工但终检失败，产品被隔离并进入返工，最终从序列号查询完整谱系。关闭云端模型连接后，继续完成一个普通工单，以证明 MES 不依赖大模型运行。
